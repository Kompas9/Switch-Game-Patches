# Fire Emblem: Fortune's Weave patches

Both packages support **game version 1.1.0**, Title ID `04007EF01F8AE000`, main
Build ID `DB93B0125F4850601D61C3EDDE012F8EB2ECFE77`.

| Patch | Version | Details |
| --- | --- | --- |
| 60 FPS unlock + timing adjustment | v1.0 | [Instructions and limits](README-60FPS.md) |
| 3440x1440 ultrawide fix | v1.1 | [Camera, UI, world markers, menu effects and 16:9 movies](ULTRAWIDE.md) |

Download ZIPs from the [main README](../../README.md#download-zips) or
[Releases](https://github.com/Kompas9/Switch-Game-Patches/releases).
The FPS and ultrawide mods can be enabled together. The combined ultrawide mod
replaces all earlier camera/UI/movie aspect test folders; disable those first.
Read the per-patch instructions for graphics settings and supported Build IDs.

# v1.4 - Fire Emblem ultrawide v1.2

Updates the 3440x1440 (43:18) patch for Fortune's Weave game version 1.1.0.

- Fixes the radar charts on the unit screen's Stats page (basic, battle and growth-rate): the polygons were displaced from their circles.
- Everything else is unchanged from ultrawide v1.1.

Replace previous ultrawide mods, including v1.1, with **Ultrawide-3440x1440-v1.2**. Keep the FPS mod separate. Use Stretch to Window and 3440x1440 output. No emulator rebuild is required.

The charts are drawn by the game outside the UI layout, so the earlier UI fix did not reach them. v1.2 is v1.1 plus five patch records. Limited visual testing and an offline emulation of the new code passed; no full-playthrough guarantee.

Torch-light flicker after initial loading remains under investigation and has also been reported without ultrawide. This release does not include an emulator or lighting fix. FPS packages are unchanged.
